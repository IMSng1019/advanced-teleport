# 路口、世界隔离与睡眠 TP 修复验证

验证日期：2026-11-04。环境：Windows、JDK 21、Minecraft 1.20.4、Fabric Loader 0.16.10、Fabric API 0.97.3+1.20.4。

## 修复及回归证据

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 有护栏的蓝冰十字路口断网 | 路口各侧允许为完整护栏或同宽有效支路，保持完整地面和两格净空要求 | 3/5 格宽 T 型、十字、L 弯各方向可达；破损护栏/地板、障碍拒绝；拆除局部重算、旧上传拒绝、未加载区块保留未知状态 |
| 嵌套世界末级同名导致串库 | 使用相对于默认存档根的完整规范化路径；跨盘使用绝对路径 | 普通旧目录兼容、嵌套世界分离、路径规范化、安装目录重定位、自定义 universe、根目录、Windows 跨盘，共 7 项新增测试 |
| 睡眠 TP 保留旧床状态及非鞘翅垂直速度 | 使用原版命令的传送重载，并按原版处理速度和接地状态 | 实际 Minecraft 床与玩家、TP 请求/响应验证唤醒和床释放；再次唤醒不返回旧床；普通玩家清除垂直速度、鞘翅玩家保留速度及飞行状态 |

新增测试先验证了旧实现失败：道路测试有 4 项失败；原样提取旧 basename 规则后，世界身份测试有 5 项失败；真实 Minecraft 测试复现了睡眠未解除和非鞘翅垂直速度未清除两个失败。修复后全部通过。

- 普通平级世界继续读取原数据；旧版曾混用的嵌套或自定义 universe 数据库保留，不自动归入任一新目录。迁移这类注册数据需要先确认其世界归属。
